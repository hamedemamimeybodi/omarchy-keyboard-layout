# Contributing

This fork preserves the original project's licenses and authorship. Keep source changes focused and include reproducible model/native tests. Changes remain under the applicable MIT terms in LICENSE and native/LICENSE. No CONTRIBUTING file or CLA requirement was found in the verified 0.2.3 baseline; recheck the current upstream policy before proposing upstream work.

Run the tests in README.md. Separate static checks, private transport tests, operator reports and independent live observations. Do not claim a live test passed without observing it. Preserve public author attribution and avoid credentials, private paths, desktop logs and machine-specific evidence in commits or issues.

Send narrowly scoped namespace/scope/filter patches upstream when practical; keep fork-specific publication documentation separate. A real GitHub fork and authenticated public author identity are required before posting the prepared upstream PR. Community announcement drafts are for human review; do not post them automatically.
